# [KPA_Project] 탐사(Exploration) 시스템 최종 명세서 (Final Spec)

본 문서는 탐사 시스템의 조작 방식, 데이터 구조, 시퀀스 연출 및 기믹 상호작용에 대한 모든 기획 및 기술 명세를 통합한 최종 가이드입니다.

---

## 🎮 1. 조작 및 경로 생성 (Path Management)

### **A. 시점 전환 (Camera Phase)**
1.  **Planning (탑뷰)**: 맵 로딩 후 전체 지도를 수직으로 내려다보는 시점으로 시작합니다. 경로를 설계하는 단계입니다.
2.  **Moving (쿼터뷰)**: '경로 확정' 버튼 클릭 시 카메라가 부드럽게 대각선 시점(Quarter-view)으로 전환되며 실제 이동이 시작됩니다.

### **B. 드래그 방식 드로잉 (Continuous Drawing)**
- **경로 그리기**: 마우스 좌클릭 상태로 그림판을 그리듯 자유롭게 이동 경로를 생성합니다.
- **벽 충돌 감지**: `Obstacle` 레이어에 드래그가 닿으면 그리기가 자동으로 즉시 중단됩니다.
- **지능형 연결**: 단일 클릭 또는 끊긴 지점에서 다시 클릭 시, **Unity NavMesh**를 사용하여 이전 지점과 현재 지점 간의 **최단 경로**를 자동 생성하여 이어줍니다.
- **실행 취소(Undo)**: 마우스 우클릭 시 마지막으로 드래그했던 세그먼트 구간을 통째로 삭제합니다.

### **C. 가변 키 매핑**
- 기본 상호작용 키는 **`KeyCode.E`**이나, `ExplorationManager`를 통해 모든 입력 키를 동적으로 변경할 수 있도록 설계합니다.

---

## 🔍 2. 오브젝트 및 상호작용 (Interaction Types)

탐사 맵은 세 가지 타입의 노드로 구성됩니다.

### **A. 단서 (Clue)**
- **획득**: 캐릭터가 설정된 `clueRange` 내에 진입 시 UI 알림과 함께 자동으로 수집됩니다 (`foundObjectIds` 등록).
- **UI 확인**: 탐사 HUD에 **'수집한 단서 목록'** 버튼/패널을 추가하여, 이번 탐사에서 수집한 단서의 이름과 설명을 실시간으로 확인할 수 있게 합니다.
- **역할**: 이후 발생하는 이벤트나 상호작용 시 특정 선택지를 해금하거나 작동 트리거 역할을 수행합니다.

### **B. 이벤트 (Event)**
- **실행**: 캐릭터가 이벤트 범위 진입 시 즉시 실행됩니다.
- **구조**: **비주얼 노벨(VN) 형식의 컷씬** 재생 → 선택지 팝업 → 결과값 반영.
- **VN 연출**: 배경, 인물 스탠딩 일러스트, 대화창이 포함된 비주얼 노벨 레이아웃을 사용합니다.

### **C. 상호작용 (Interaction)**
- **안내**: 캐릭터가 `interactionRange` 내에 진입 시 매핑된 키를 보여주는 안내창(`E 조사하기`)을 띄웁니다.
- **실행**: 유저가 키를 누를 때 컷씬 또는 설정된 맵 기믹 이벤트가 재생됩니다.
- **기능**: 주로 닫힌 문 열기, 통로 변경 등 맵의 구조적 변화를 일으킵니다.

---

## 🧬 3. 기믹 변화 및 경로 재작성 (Gimmick & Redraw)

- **경로 재설계 유도**: 함정으로 인한 이동 불가 환경이 되거나, 상호작용으로 맵의 경로가 바뀐 경우 캐릭터가 멈추고 페이즈를 다시 **`Planning` (그리기 모드)**으로 전환합니다.
- **작동 원리**: 이벤트 결과값에 `shouldRedrawPath` 플래그가 포함되어 있을 경우, 기존 남은 경로를 초기화하고 유저가 새로운 상황에 맞춰 경로를 다시 그리게 합니다.

---

## 💾 4. 데이터 보존 (Persistence)

- **즉시 세이브**: 모든 탐사 성공/실패 시 획득한 골드와 단서 리스트를 `GameState`에 즉시 반영하고 `SaveSystem.Save()`를 통해 보존합니다.
