# [KPA_Project] 탐사 시스템 개편 상세 실행 계획서 (개정안)

본 문서는 비주얼 노벨 형식의 컷씬 연출과 가변 키 매핑 시스템을 포함한 탐사 시스템 전면 개편의 상세 설계안입니다.

---

## 🛠️ 1. 비주얼 노벨(VN) 기반 컷씬 시스템

### **A. UI 및 연출 구성**
- **VNDialoguePanel**: 상하단 블랙바(또는 투명 바), 중앙 일러스트, 하단 텍스트 박스로 구성된 전용 레이아웃을 사용합니다.
- **캐릭터 스탠딩**: 이벤트 데이터에 지정된 좌/우 캐릭터 이미지(`Sprite`)를 실시간으로 교체하며 연출합니다.
- **메시지 타이핑**: 텍스트가 한 글자씩 출력되는 효과와 클릭 시 스킵/다음 대화 진행 기능을 포함합니다.

### **B. 데이터 구조 (ExplorationDialogue)**
- `List<DialogueStep>` 형태로 구성하여 한 노드에서 여러 차례의 대화가 가능하도록 설계합니다.
- 각 단계별 포함 항목: 캐릭터 이름, 대화 내용, 왼쪽 일러스트, 오른쪽 일러스트, 배경음(BGM) 등.

---

## 🎧 2. 사용자 입력 및 가변 키 매핑

- **상호작용 키(Interact Key)**: 
    - 코드 상에 `KeyCode.E`로 하드코딩하지 않고, `ExplorationManager`의 필드로 관리하여 인스펙터나 설정 메뉴에서 언제든 매핑 가능하도록 구현합니다.
- **UI 동적 표시**: 상호작용 가능 거리 진입 시 화면에 뜨는 안내 문구(`[E] 조사하기`)에 현재 매핑된 키가 자동으로 반영되도록 처리합니다.

---

## 🧬 3. 고급 상호작용 및 경로 재작성 흐름

1.  **단서 수집**: 캐릭터가 단서 노드의 특정 범위(`clueRange`)에 진입 시 UI 알림과 함께 자동 수집.
2.  **상호작용 실행**: 상호작용 노드 근처에서 매핑된 키를 누를 경우 이동을 멈추고 지정된 컷씬/이벤트 실행.
3.  **기믹 및 경로 재설계**: 
    - 이벤트 결과값에 `shouldRedrawPath = true`가 포함된 경우 캐릭터 정지.
    - 현재 페이즈를 **`Planning` (그리기 모드)**으로 강제 전환.
    - 유저는 변경된 맵 상황(문 열림 등)에 맞춰 새로운 경로를 다시 작성해야 함.
