# 🎨 기획자 작업 가이드 (Level Designer Guide)

이 문서는 **개편된 탐사 시스템(2026-04-10)**에 맞춰 기획자가 유니티 에디터에서 노드를 설정하고 이벤트를 디자인하는 표준 방법을 설명합니다.

---

## 1. 씬 오브젝트 배치 및 이름 규칙
기획자가 씬에 배치한 오브젝트의 **이름 접두사**를 통해 시스템이 노드 성격을 파악합니다.

| 이름 접두사 | 담당 마커 | 역할 |
| :--- | :--- | :--- |
| `START_` | `ExplorationStartMarker` | 캐릭터 시작 위치 |
| `ENV_` | `ExplorationNodeMarker` | 환경 오브젝트 (수집 아이템) |
| `OBJ_` | `ExplorationNodeMarker` | 일반 상호작용/이벤트 지점 |
| `EXIT_` | `ExplorationNodeMarker` | 탈출구 |

> [!TIP]
> 씬 뷰에서 노드 마커를 선택하면 나타나는 **파란 원(수집 범위)**과 **노란 원(상호작용 범위)**을 드래그하여 직관적으로 조절할 수 있습니다.

---

## 2. 노드 데이터 설정 (`ExplorationNodeData`)

### 2.1 진입 조건 (`Requirements`)
이벤트 발동을 위한 **최소 조건**입니다. 만족하지 못하는 캐릭터는 해당 노드에 접근해도 아무런 반응 없이 통과합니다.
- `StatAtLeast`: 특정 스탯 수치 이상
- `HasEnvObject`: 탐사 중 습득한 단서/도구 보유 여부
- `HasItem`: 실제 인벤토리 내 아이템 보유 여부

### 2.2 강제 효과 (`Force Effects`) - **[NEW]**
노드에 진입했는데 **가용한 선택지가 하나도 없을 경우** 자동으로 발동되는 패널티 및 효과입니다. 
- 예: 함정 노드에 들어갔는데 해제할 도구(선택지)가 없다면, `Time` 효과로 10초 차감 후 자동으로 후퇴하게 됩니다.

---

## 3. 선택지 디자인 (`ExplorationChoiceData`)

### 3.1 4대 선택지 타입 (`ChoiceType`)
시스템 로직이 분기되는 핵심 분류입니다.

| 타입명 | 핵심 기능 |
| :--- | :--- |
| **`Combat`** | 선택 시 **적 조우 티켓 1장을 자동으로 소모**합니다. 티켓이 없으면 선택지가 숨겨집니다. |
| **`Interact`** | 일반적인 모든 상호작용(조사, 사용, 대화)에 사용합니다. |
| **`Escape`** | 후퇴하거나 피하는 선택지입니다. 보통 `shouldRedrawPath`와 함께 사용합니다. |
| **`Exit`** | 탐사를 성공적으로 종료하고 정산 화면으로 즉시 이동합니다. |

### 3.2 결과 효과 통합 리스트 (`Effects`)
과거의 개별 변수(`goldReward` 등) 대신, 하나의 리스트에 여러 효과를 자유롭게 조합하여 넣습니다.

*   **`Gold`**: 골드 획득(양수) 또는 차감(음수)
*   **`Time`**: 탐사 시간 차감 (초 단위)
*   **`EnemyTickets`**: 적 전용 선택권 개수 조절
*   **`EnvObjectGain / Loss`**: 탐사 전용 단서/임시 아이템 획득 및 소모 (예: 열쇠)
*   **`ItemGain / Loss`**: 실제 메인 가방 아이템 획득 및 영구 소모 (예: 물약, 영구 장비)

---

## 4. 작업 예시: "힘으로 민다" 선택지 구성
1.  **Label**: `"힘으로 민다"`
2.  **Type**: `Interact`
3.  **Requirements**: `StatAtLeast` (Strength 25), `HasItem` ("IronGloves")
4.  **Effects**: 
    - `Time` (Amount: 5)
    - `Gold` (Amount: 100)
    - `ItemLoss` (Target: "IronGloves" - 장갑 파손 연출 등)
