# KPA_Project 리팩토링 및 탐사 프로토타입 최종 보고서

본 문서는 리팩토링(이벤트 시스템), 버그 수정, 그리고 새로운 탐사 콘텐츠 프로토타입 구현 내역을 종합한 보고서입니다. 사용자가 컴퓨터 복귀 시 Unity 에디터에서 확인해야 할 **수동 검증 단계**가 포함되어 있습니다.

---

## 🛠️ 1. 아키텍처 및 시스템 개선 내역

### [이벤트 기반 시스템 도입]
- **변경 사항**: `GameManager.cs`와 `UIController.cs` 간의 직접적인 호출을 제거하고 `GameEvents.cs`라는 중앙 이벤트 버스를 도입했습니다.
- **효과**: 시스템 간 결합도가 낮아져 향후 사운드, 이펙트, 업적 등 새로운 기능을 추가할 때 기존 코드를 수정하지 않고 독립적으로 연동할 수 있습니다.

### [주요 버그 수정]
- **씬 전환 오류**: `Main` vs `MainScene` 혼용으로 인해 전투 후 메인 화면으로 돌아오지 못하던 버그를 수정했습니다.
- **세이브 데이터 강화**: 퀘스트 수락 시 정보가 저장되지 않아 재시작 시 사라지던 문제를 `SaveSystem.cs` 수정을 통해 해결했습니다.

## 🧱 2. '탐사(Exploration)' 및 '낮 행동' 개선

### [탐사 프로토타입]
- **핵심 로직**: 경로 드래그 계획 -> 자동 이동(시간 실시간 소모) -> 위험 조우 -> 선택지(스탯/아이템 조건 체크) -> 결과 정산.
- **워크플로우 자동화**: Blender에서 `TRAP_`, `OBJ_` 접두사 모델링 시 Unity에서 스크립트가 자동 세팅됩니다.

### [낮 행동 UI & 루프 리팩토링]
- **명확한 루프**: 지도 -> 장소 이동(행동권 1 소모) -> 장소 내 행동(무제한) -> 지도 복귀 시도(행동권 소진 시 즉시 밤 전환).
- **공간감(Identity) 부여**: `LocationThemeData`를 도입하여 장소별 고유 색상과 배경, 버튼 가시성을 제어합니다.
- **장소별 고유 기능**:
  - **집**: 무료 휴식.
  - **상점**: 장비 구매 및 판매.
  - **훈련장**: 시설 업그레이드(효율 상승) 및 훈련 보조.
  - **카페**: 고급 휴식(골드 소모) 및 음식 구매.
  - **의뢰 게시판**: 최대 3개 의뢰, 일일 1회 리롤 기능.
- **모듈화**: `GlobalHUDController`와 `PlaceActionUIController`로 UI 로직을 분산하여 난잡함을 해소했습니다.
